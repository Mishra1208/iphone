# iPhone Duo — Rare air. (Concept Landing Page)

> **Concept Prototype:** Digital Marketing & IMC project (iPhone Duo India launch campaign).

---

## 📱 Overview

**iPhone Duo** is a concept landing page for Apple's first foldable smartphone, designed specifically for the India market launch.

Closed, it’s an iPhone with a 5.4-inch outer cover display. Open, it’s an entrance into an expansive 7.6-inch inner folding display crafted from mirror-polished grade 5 aerospace titanium.

---

## ✨ Key Features

- **3D Foldable Phone Simulation:** Built with pure CSS 3D transforms, dual-sided display rendering, realistic creases, and scroll-driven opening/closing animation.
- **Interactive Storage & Price Calculator:** Instant switching between 256GB (₹2,99,900), 512GB (₹3,24,900), 1TB (₹3,74,900), and 2TB (₹4,49,900) with smooth counter transitions.
- **Pre-Order Live Countdown:** Real-time countdown clock counting down to October 16, 2026.
- **Interactive Private Demo Pass:** Book appointments at Apple BKC (Mumbai) or Apple Saket (Delhi). Features a realistic 3D holographic card with cursor-tracking lighting reflections, procedural security matrix code, and instant pass generation.
- **Interactive Hardware Specs Modals:** Interactive modals covering Aerospace Grade 5 Titanium, Dual 48MP Camera system, A20 Pro chip, Dual-Battery system (up to 44 hours playback), and IP68 Ceramic Shield durability.
- **AEO & SEO Optimized:** Complete Schema.org JSON-LD microdata (`Product`, `FAQPage`, `BreadcrumbList`) and semantic structure.
- **100% Self-Contained:** Zero external frameworks or heavy libraries. Pure semantic HTML5, modern CSS3, and lightweight vanilla JavaScript.

---

## 🛠️ Technology Stack

- **HTML5:** Semantic architecture, accessible landmarks, and rich metadata
- **CSS3:** Custom properties (CSS variables), CSS 3D perspective transforms, backdrop filters, responsive grid & scroll-snap rails
- **Vanilla JavaScript:** IntersectionObserver scroll reveals, animation frames, procedural code generation, and DOM manipulation
- **Hosting:** GitHub Pages with `.nojekyll`

## 🚀 Viewing Locally

Simply open `index.html` in any modern web browser, or run a local dev server:

```bash
# Python 3
python3 -m http.server 8000

# or npx serve
npx serve .
```

Visit `http://localhost:8000` to interact with the experience.
